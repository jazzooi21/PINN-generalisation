# PINN-generalisation

Code written for [Improving Generalisability of Physics-Informed Neural Networks](https://drive.google.com/file/d/1Y7Y94mp8eC9p11tVgGaHQYTemYQlH0oC/view?usp=sharing).

Neural network training done with PyTorch.

Black-Scholes test was ultimately decided to be removed.

`state_dicts` can be used to load NNs parameters for testing (use `model.load_state_dict()`).
